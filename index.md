# Homelab Backups

A personal backup utility operated by [ArlisKo](https://github.com/ArlisKo). It creates recovery archives of the owner’s vehicle-maintenance and price-tracking applications and saves them to the owner’s Google Drive.

The utility uses rclone and Google OAuth. Its `drive.file` permission covers files created by, or explicitly shared with, the utility. It uploads and verifies recovery archives for personal disaster recovery. There is no public sign-up service.

This site provides information only. Backup archives, private applications, records and credentials are not hosted here.
